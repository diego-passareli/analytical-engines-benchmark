# Resultados do Benchmark

Os CSVs de resultado de cada execução devem ser colocados aqui.
Formato esperado: `{suite}_{SF}_YYYYMMDD_HHMMSS.csv`

Exemplos:
- `tpcds_sf1_20260930_133613.csv`
- `tpcds_sf10_20260930_152117.csv`
- `clickbench_20260929_231522.csv`
- `real_20260930_204407.csv`

Ver `environment.md` para descrição das colunas.
